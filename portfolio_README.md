## ✨ Features

- **Animated hero** with floating particle canvas, drifting geometric shapes, and orbiting avatar ring
- **3-column research grid** with staggered scroll animations, mouse-tracking glow, and floating purple circle shapes
- **Interactive contact cards** with paper squish and skew effect on cursor entry
- **"Open to Opportunities"** card with 3D tilt following cursor position
- **Embedded PDFs** for downloadable research papers (no external hosting needed)
- **Embedded video** for Wine Research Centre work experience
- **Animated skill bars** that fill on scroll into view
- Fully **self-contained** — one `.html` file, works offline

## 🚀 Deploy

**Option 1 — Netlify Drop (30 seconds)**
1. Go to [netlify.com/drop](https://app.netlify.com/drop)
2. Drag and drop `portfolio.html`
3. Get a live link instantly

**Option 2 — GitHub Pages**
1. Create a repo named `jkenrickk.github.io`
2. Upload `portfolio.html` renamed to `index.html`
3. Enable GitHub Pages in repo Settings → Pages
4. Live at `https://jkenrickk.github.io`
