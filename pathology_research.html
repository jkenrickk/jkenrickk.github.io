Abstract

Keywords

Invasive Ductal Carcinoma RNA-seq DNA Methylation Tumour Heterogeneity GSEA Kaplan-Meier NMF Multi-Omics

Background. Invasive ductal carcinoma (IDC) accounts for approximately 80% of all breast cancer diagnoses and exhibits marked transcriptomic and epigenomic heterogeneity that confounds prognostication and therapeutic stratification. Elucidating the molecular architecture of IDC subtypes is a prerequisite for precision oncology.

Methods. We performed integrative multi-omics profiling of 412 IDC specimens and 88 matched adjacent-normal controls using RNA-seq (18,240 genes), Illumina EPIC methylation arrays (3,817 CpG sites), and low-pass whole-genome sequencing for copy-number inference. Differential expression was computed via DESeq2 with BH-corrected FDR < 0.05. Non-negative matrix factorisation (NMF) was applied for consensus molecular subtyping. Survival analysis employed Cox proportional-hazards regression.

Results. We identified 2,134 differentially expressed genes (1,089 upregulated; 1,045 downregulated) and three reproducible molecular subtypes (IDC-S1, IDC-S2, IDC-S3) with distinct epigenomic and transcriptomic signatures. IDC-S3 exhibited focal amplification of chromosome 17q12 encompassing ERBB2, pervasive promoter hypermethylation of DNA-damage repair loci, and significantly inferior overall survival (HR = 2.41; 95% CI 1.78–3.26; p < 0.001). Immune evasion pathway enrichment was highest in IDC-S1.

Conclusions. Multi-omics subtyping of IDC reveals clinically actionable transcriptomic and epigenomic distinctions. IDC-S3 represents a high-risk subgroup warranting prospective evaluation of targeted ERBB2 inhibition combined with epigenetic reprogramming strategies.

Section 4 — Clinical Outcomes

Section 5 — Pathway Analysis

Gene Set Enrichment and Pathway Dysregulation

GSEA was performed against MSigDB Hallmark gene sets (n=50) and KEGG pathways (n=186). Enrichment scores were computed using the weighted Kolmogorov–Smirnov statistic. NES ≥ 1.5 or ≤ −1.5 at FDR < 0.25 were considered significant.

Section 6 — Methods

Materials and Methods

A complete description of data acquisition, pre-processing pipelines, statistical frameworks, and software versions used throughout this analysis.

Total RNA was extracted from fresh-frozen tissue using TRIzol reagent (Thermo Fisher). Libraries were prepared using the Illumina TruSeq Stranded Total RNA kit with Ribo-Zero Gold depletion. Paired-end 150 bp sequencing was performed on the NovaSeq 6000 to a target depth of 50M reads per sample. Reads were aligned to GRCh38 (GENCODE v43) using STAR v2.7.10a with default parameters. Gene-level counts were quantified with featureCounts (Subread v2.0.3). Quality metrics were assessed with FastQC and MultiQC.
Count matrices were imported into R v4.3.1 using DESeq2 v1.40.2. Low-count genes (fewer than 10 reads across 80% of samples) were removed prior to analysis. The design formula ~ batch + group was used, with batch as a known technical covariate estimated from RNA-seq principal components. Wald tests were used to compute log₂ fold changes and associated standard errors. Multiple testing correction applied the Benjamini–Hochberg procedure at FDR < 0.05. Results were exported and annotated against Ensembl release 110.
EPIC 850K arrays were processed using minfi v1.46.0 in R. Functional normalisation was applied via preprocessFunnorm. Probes with detection p > 0.01, cross-reactive probes, probes overlapping SNPs (MAF ≥ 0.01, dbSNP v151), and sex-chromosome probes were removed. Beta values were converted to M-values for linear modelling. Differentially methylated positions (DMPs) were identified using limma v3.56 with BH correction at FDR < 0.05 and |Δβ| ≥ 0.15.
Consensus non-negative matrix factorisation (cNMF) was applied to the top 5,000 most variable genes (by MAD) across the 412 IDC samples using NMF v0.26 in R. Factorisation rank was selected by cophenetic correlation coefficient stability across 200 bootstrap iterations. The optimal rank k=3 was confirmed by both stability and silhouette score maximisation. Cluster assignments were validated using an independent TCGA BRCA subset (n=186).
Overall survival (OS) was defined as time from diagnosis to death from any cause or censoring at last follow-up. Disease-free survival (DFS) was defined as time to locoregional recurrence, distant metastasis, contralateral cancer, or death. Kaplan–Meier curves and log-rank tests were computed using survival v3.5.7 and plotted with survminer v0.4.9. Multivariable Cox regression included molecular subtype, age at diagnosis (continuous), tumour stage (I–IV), and receptor status as covariates. Proportional hazards assumption was verified using Schoenfeld residuals.
Gene set enrichment analysis was performed using fgsea v1.26 with 10,000 permutations against MSigDB Hallmark (v2023.1) and KEGG (March 2024) gene sets. Genes were ranked by Wald statistic from DESeq2 to preserve both direction and magnitude information. Normalised enrichment scores (NES) ≥ 1.5 or ≤ −1.5 at FDR < 0.25 were reported. For pathway visualisation, leading-edge gene sets were extracted and subjected to network analysis in Cytoscape v3.10.
All computationally intensive steps (alignment, NMF bootstrapping, GSEA permutation) were executed on the Compute Canada Cedar HPC cluster (2,048-core Slurm environment) and validated on AWS EC2 (r6i.8xlarge). All analysis code is version-controlled at GitHub (jkenrickk/idc-multiomics) under MIT licence. Containerised environments using Docker (Bioconductor 3.17 base image) ensure full computational reproducibility. Pipeline orchestration was managed with Snakemake v7.32.
